**Function Name:** `uuidv7()`

**PostgreSQL Version:** PostgreSQL 18

**Summary:** PostgreSQL 18 introduced native UUIDv7 support with the built-in `uuidv7()` function. This function generates UUID version 7 identifiers according to RFC 9562, with an optional interval parameter to generate UUIDv7 values for different timestamps. PostgreSQL 18 also added `uuidv4()` as an alias for consistency with the existing `gen_random_uuid()` function.
